How this node decides

1. Rule engine scores ACS712 + DS18B20 features vs thresholds.

2. When the labeled dataset is statistically sufficient, Gaussian NB is fitted on-device.

3. If NB confidence ≥ 60% and ≥ rule confidence, NB overrides the warning banner.

Features for NB exclude powerW (derived as 230×|I|). Labels come from threshold + temperature checks on each batch average.
